How source links are handled

Source links open the original public record in a new tab. When a link is unavailable, the item shows “The original source link is currently unavailable” and the item remains published.

Public data fields

Each update carries only these public fields:

  • public_item_id
  • title
  • summary
  • why_it_matters
  • source_name
  • source_url (or unavailable)
  • source_date
  • event_date (optional)
  • published_date
  • relevance
  • display_topic
  • lifecycle (optional)
  • topic_ids
  • entity_ids
  • place_ids
  • sensitivity_display
  • verification_display
  • related_item_ids
  • release_id

Excluded internal data

SilverLeaf Brief never exposes:

  • reviewer notes and review decisions
  • candidate records and evidence excerpts
  • dedupe and signal metadata
  • internal file paths and run identifiers
  • sensitivity rationale
  • logs and unpublished source proposals

Coverage limitations

This release reflects reviewed updates only; it is not complete county coverage and is not real-time. See Coverage & limitations for the full scope statement.
